# Landing Page Program Prioritas Transmigrasi

Landing page untuk menampilkan 5 program prioritas Kementerian Transmigrasi Republik Indonesia (Program 5T):
1. Trans Tuntas
2. Trans Lokal
3. Trans Gotong Royong
4. Trans Patriot
5. Trans Karya

## Fitur

- Desain modern dan responsif
- Animasi scroll yang smooth
- Tampilan yang optimal di berbagai perangkat
- Navigasi yang mudah digunakan
- Informasi detail untuk setiap program
- Loading animation yang menarik

## Teknologi

- HTML5
- CSS3 (dengan animasi dan transisi modern)
- JavaScript (Vanilla)
- Optimasi SEO
- Mobile-first approach

## Cara Menjalankan

1. Clone repository ini
```bash
git clone https://github.com/[username]/LandingPageProgramPrioritasTransmigrasi.git
```

2. Buka file `index.html` di browser Anda
